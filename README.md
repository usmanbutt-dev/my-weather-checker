# Weather Checker

A browser exercise that looks up current weather for a city using OpenWeatherMap.

**[Open the demo](https://usmanbutt-dev.github.io/my-weather-checker/)**

## How it works

Enter a city and click the weather button. The page requests OpenWeatherMap's current-weather endpoint, displays the weather category, and converts the returned temperature from Kelvin to Celsius.

## Run locally

Open `index.html` in a browser. The page uses `script.js` and `style.css`, with no build step. A working OpenWeatherMap API key and network access are required for weather results.
